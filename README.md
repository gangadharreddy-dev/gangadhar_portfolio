## 🎯 Overview

A world-class, Framer-quality personal portfolio designed to feel like a **premium SaaS product website** rather than a traditional student portfolio. It combines **Apple-inspired minimalism**, cinematic animations, glassmorphism UI, and modern micro-interactions — all while remaining blazing fast, fully responsive, and SEO-optimized.

### ✨ Design Philosophy

| Principle | Implementation |
|-----------|---------------|
| **Dark Luxury Theme** | Deep space background (`#030014`) with purple/cyan/indigo accent palette |
| **Glassmorphism** | Frosted glass cards with `backdrop-blur`, soft borders, and layered transparency |
| **Cinematic Animations** | Framer Motion entrance reveals, staggered transitions, and scroll-triggered effects |
| **Premium Micro-interactions** | Mouse spotlight tracking, 3D hover tilts, glowing aura rings, floating shapes |
| **Smooth Scrolling** | Lenis-powered buttery smooth scroll experience across the entire site |

## 🚀 Getting Started

### Prerequisites

- **Node.js** >= 18.x
- **npm** >= 9.x

### Installation

```bash
# Clone the repository
git clone https://github.com/gangadharreddy-dev/gangadhar_portfolio.git
cd gangadhar_portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

The app will be running at [Live Demo](https://gangadhar-portfolio-gamma.vercel.app/)

### Build for Production

```bash
npm run build
```

Output will be in the `dist/` folder, ready for deployment.
